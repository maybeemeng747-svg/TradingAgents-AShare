## Key Logic

### TAProfile (api/ta_profile.py)
- Four profiles: MIDLINE_POLICY_LIGHT, SHORT_TECH_LIGHT, POSITION_RISK_LIGHT, FULL_TA
- Each profile declares enabled_analysts, enabled_risk_modules, enabled_managers
- `recommend_profile()` routes by candidate_type, research_queue, analysis_intent, has_position
- `filter_analysts_for_profile()` restricts selected analysts to profile's enabled set

### RuntimeTier (api/runtime_tier.py)
- Three tiers: FAST_RADAR, LIGHT_RESEARCH, FULL_TA
- FULL_TA requires_confirmation=True, cost_risk=high
- TradeFlow endpoints default to FAST_RADAR

### /v1/analyze Integration (api/main.py)
- Default tier: LIGHT_RESEARCH (not FULL_TA)
- dry_run bypasses FULL_TA confirmation gate
- FULL_TA requires confirmed_full_ta=True
- Profile auto-resolved from tier and user context

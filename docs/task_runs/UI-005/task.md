# UI-005: 盘后 Review 前端页面

## 目标
把 M-007 盘后复盘结果展示到前端，按策略、层级、候选日期统计命中率、误报率、失效率和后续调参建议。

## 约束
- 只做策略质量复盘，不做个股买卖建议
- 0% 必须显示为 0.0%，不能显示 N/A%
- 代码标注：`// [UI-005] tradeflow_review_page`

## 实现

### 1. 在 TradeFlow 页面增加第 4 个 Tab
Tab: 候选池 | 盘中观察 | TA 队列 | 盘后 Review

### 2. 盘后 Review Tab
调用 getTradeFlowReview(date) 获取数据。

展示内容：
- **总体概览卡片**：
  - 总候选数、有评分数、无数据数、命中数、误报数、失效数
  - 总命中率、总误报率
  - 平均次日/3日/5日收益

- **策略命中率表格**：
  - 列：策略 | 总数 | 命中 | 误报 | 无数据 | 失效 | 命中率 | 误报率 | 平均次日 | 平均3日 | 平均5日
  - 排序按命中率降序

- **分层统计表格**：
  - 列：层级 | 总数 | 命中 | 误报 | 无数据 | 失效

- **移除理由列表**
- **调参建议列表**

### 3. 验证

```bash
cd frontend && npm run build
```

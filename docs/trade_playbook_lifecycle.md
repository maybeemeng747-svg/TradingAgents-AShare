# A股跟进看板战法契约：上车—在车上—下车

> 本文是 TA 系统的交易生命周期契约草案，供跟踪看板、观察仓、TA 报告语义层和 investment-controller 共用。
> 目标不是自动下单，而是让系统每次讨论一只股票时先讲清楚：当前在哪个阶段、用哪一类仓位、什么证据允许前进、什么证据要求撤退。

## 1. 总纲

核心目标：

> 看对时尽量留在车上，看错时不能被一把打死。

系统原则：

- 上车分批，不一把梭。
- 加仓不是因为跌了，而是因为确定性增强。
- 持仓后必须拆分核心仓、机动仓、防守仓。
- 高抛优先处理机动仓，不轻易卖核心仓。
- 低吸必须等风险释放和承接确认，不在第一次大跌或跌停时补。
- 下车分为赚钱下车和证伪下车，不能混淆。
- 单票不得无限重仓，题材弹性票尤其要设置硬上限。

## 2. 生命周期阶段

TA 与跟踪看板使用统一阶段枚举：

| 阶段 | 含义 | 允许动作 |
| --- | --- | --- |
| `observe` 观察 | 有逻辑线索，但证据或位置不足 | 加入观察仓、等待触发 |
| `trial` 试错 | 逻辑像，仓位小，错了不伤账户 | 试错仓 |
| `confirm` 确认 | 产业/业绩/资金至少两类证据增强 | 确认仓 |
| `attack` 进攻 | 已确认后出现高赔率窗口 | 回踩进攻仓或突破进攻仓 |
| `hold` 持有 | 已在车上，逻辑未证伪 | 拆分核心/机动/防守仓 |
| `risk` 风控 | 价格或逻辑出现风险暴露 | 减机动仓、减到核心仓 |
| `exit` 退出 | 投资假设证伪或重大风险 | 退出核心仓也可被允许 |

## 3. 计划仓位上限

每次买入前必须先判断最大计划仓位。默认参考：

| 标的类型 | 最大计划仓位 |
| --- | ---: |
| ETF / 指数类 | 10%—20% |
| 硬逻辑主板龙头 | 10%—25% |
| 题材弹性股 | 5%—15% |
| 业绩未验证但想试错 | 3%—10% |
| 高波动、监管风险、传闻票 | 1%—5% |
| 单票绝对上限 | 不超过总资产 40% |

若当前持仓已超过计划仓位，系统不得提示继续加仓，只能提示持有、减仓或等待确认。

## 4. 上车三笔法

计划仓位拆成三笔：

| 仓位 | 比例 | 作用 |
| --- | ---: | --- |
| 试错仓 | 计划仓位的 1/3 | 先上车，防止完全踏空 |
| 确认仓 | 计划仓位的 1/3 | 逻辑被证据验证后加仓 |
| 进攻仓 | 计划仓位的 1/3 | 已确认后在高赔率窗口加仓 |

三分之一不是越跌越买，而是越确定越买。

### 试错仓

允许条件：

- 投资假设清晰。
- 当前价格不是连续暴涨后的极端高位。
- 板块没有明显退潮。
- 买入后可接受 5%—8% 亏损。
- 仓位足够小，错了不伤账户。

禁止条件：

- 纯传闻，无公告、订单、产业证据。
- 连续涨停后高开追入。
- 当天爆量冲高回落。
- 已严重偏离基本面。
- 用户现金不足或总仓位过高。

### 确认仓

确认仓不是看股价涨，而是看证据是否增强。至少满足以下三类中的两类：

- 产业证据：必需环节、客户认证、订单/中标、产能投放、收入传导、不是蹭概念。
- 业绩确认：预告超预期、财报改善、毛利率改善、主营增长、新业务放量、订单转收入。
- 资金确认：放量上涨未快速砸回、回调缩量、板块龙头同步走强、资金不是一日游。

无业绩/订单/产业事实验证时，不允许提示重仓。

### 进攻仓

进攻仓必须建立在确认仓之后，不能跳过确认仓直接加进攻仓。

回踩进攻条件：逻辑已确认、上涨后回调、回调缩量、不破平台、再次放量转强、板块健康。

突破进攻条件：逻辑已确认、板块同步走强、突破关键平台、放量但不爆量失控、突破后 1—2 天不跌回平台。

禁止在第一次大跌、跌停封死、放量破位、板块龙头集体退潮时补仓。

## 5. 在车上：仓位拆分

已持仓后系统必须拆分为：

| 仓位类型 | 默认比例 | 作用 |
| --- | ---: | --- |
| 核心仓 | 50% | 吃主升，不轻易动 |
| 机动仓 | 30% | 高抛低吸、波段操作 |
| 防守仓/现金 | 20% | 防黑天鹅、等待机会 |

若用户满仓或现金不足，系统应提示缺乏防守仓，不适合继续加仓。

核心仓只有在业绩证伪、公告澄清核心逻辑、监管问询、高位连续放量杀跌、板块系统性退潮、投资假设被推翻时才考虑退出。

机动仓用于高抛低吸：

- 盈利 15%—20% 可卖部分机动仓。
- 盈利 25%—35% 且情绪过热，可再卖部分机动仓。
- 连续加速、极端亢奋，优先减机动仓。
- 第一次大跌不补，跌停封死不补。
- 跌后缩量企稳或放量重新站回关键位，才可小接/接回机动仓。

## 6. 下车规则

赚钱下车与证伪下车必须分开。

赚钱下车：

- +15%—20%：卖机动仓的 1/3。
- +30% 左右：再卖机动仓的 1/3。
- +50% 以上：结合业绩和趋势，尽量保留核心仓。
- 极端亢奋：减大部分机动仓，只留核心。

证伪下车：

- 轻度风险：减机动仓。
- 中度风险：减到只剩核心仓。
- 重度证伪：核心仓也要退出。
- 连续跌停/重大利空：不补仓，优先保命。

证伪信号包括业绩低于预期、公告澄清核心业务、监管问询、主营逻辑不成立、高位放量连续杀跌、跌停后第二天继续弱、板块龙头集体退潮、资金撤离且无承接。

## 7. 卖飞后的追回

系统不能要求用户卖出后必须等跌回来。若卖出机动仓后继续走强，允许强势追回：

- 股价继续强势突破。
- 板块同步走强。
- 基本面没有变差。
- 突破后站稳新平台 2—3 天。
- 没有爆量冲高回落。
- 追回仓位不得超过此前卖出机动仓的一半。

## 10. 安全约束

- 禁止简单因为下跌提示补仓。
- 禁止简单因为上涨提示追高。
- 所有加仓必须说明是试错仓、确认仓还是进攻仓。
- 所有减仓必须说明是机动仓减仓、风控减仓还是证伪退出。
- 数据不足时只能输出观察或等待确认，不得输出强动作。
- 本契约不绕过现有 DECISION / Buy Level / Risk Level / 强动作门禁。

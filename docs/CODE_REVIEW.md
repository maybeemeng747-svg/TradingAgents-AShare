# 代码审查清单

> 每次代码修改后，按此清单逐项检查。适用于 OpenClaw、OpenCode、人工审查。

---

## 必查项

### 1. 生产数据安全
- [ ] 是否误改了 `tradingagents.db`（生产数据库）？
- [ ] 是否误改了 `eval_results/` 中的历史回测结果？
- [ ] 是否把测试数据写入了生产数据库？
- [ ] 是否删除了 `logs/` 中的历史日志？

### 2. Agent 框架完整性
- [ ] 新增/修改的 Agent 是否正确注册到 LangGraph 图中？
- [ ] Agent 间通信的 State 结构是否兼容？
- [ ] Prompt 模板修改是否经过审批？
- [ ] 辩论机制是否正常工作（多轮循环、裁决输出）？

### 3. 测试覆盖
- [ ] 测试是否全部通过？
- [ ] 新增逻辑是否有对应测试？
- [ ] 边界情况是否覆盖（空数据、异常值、模型超时）？

### 4. API 兼容性
- [ ] 新增接口是否有对应的前端调用？
- [ ] 修改的接口是否向后兼容？
- [ ] 错误响应格式是否一致？

### 5. 前端展示
- [ ] 新增功能是否在前端有对应入口？
- [ ] 辩论可视化是否正常渲染？
- [ ] 持仓看板数据是否正确？

### 6. 代码质量
- [ ] 是否引入了硬编码的模型 API Key？
- [ ] 是否有未处理的异常或未捕获的 Promise rejection？
- [ ] 是否有调试代码残留（print/console.log）？
- [ ] Python 代码是否通过类型检查？

### 7. 可回滚性
- [ ] 修改前是否已 `git commit`？
- [ ] 能否通过 `git revert` 回滚？
- [ ] 数据库迁移是否有对应的回滚脚本？

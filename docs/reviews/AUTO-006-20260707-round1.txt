# 项目说明

## 项目定位

TradingAgents-AShare 是一个面向 A 股投资者的多智能体投研系统，核心理念：

- **模拟真实投研机构**：14 个专业角色分工协作
- **多空辩论机制**：多头研究员 vs 空头研究员，研究总监裁决
- **多模型厂商支持**：OpenAI / Anthropic / Google / 智谱 / DeepSeek / 小米等
- **意图驱动交互**：自然语言输入，自动识别标的和周期
- **持仓追踪**：导入持仓，自动跟踪，连续分析

## 核心架构

### 1. 分析师团队（7 个）

| 角色 | 职责 | 数据源 |
|------|------|--------|
| 基本面分析师 | 财务指标、估值分析 | AKShare/BaoStock |
| 情绪分析师 | 社交媒体情绪、舆情 | AKShare |
| 新闻分析师 | 新闻事件、政策影响 | AKShare |
| 技术分析师 | K线形态、技术指标 | AKShare/BaoStock |
| 宏观分析师 | 宏观经济、利率环境 | AKShare |
| 主力资金分析师 | 大单流向、主力动向 | AKShare |
| 量价分析师 | 成交量、量价关系 | AKShare/BaoStock |

### 2. 研究员团队

- **多头研究员**：综合分析师结论，构建看多 Claim
- **空头研究员**：综合分析师结论，构建看空 Claim
- **研究总监**：裁决多空辩论，形成投资计划

### 3. 风控团队

- **风控经理**：评估风险、设置止损止盈
- **合规检查**：确保建议符合投资规范

### 4. 交易员

- 根据研究计划和风控要求，输出最终交易建议

### 5. 编排层

- **LangGraph**：状态图编排，控制 Agent 间信息流转
- **辩论机制**：多轮辩论，每轮有 Claim → Counter-Claim → 裁决

## 数据流

```
用户输入（自然语言）
  ↓
意图识别 → 标的 + 周期
  ↓
数据获取（7 路并行）
  ↓
分析师团队（7 个并行分析）
  ↓
研究员辩论（多轮）
  ↓
风控评估
  ↓
交易建议输出
  ↓
研报存储 + 通知推送
```

## 模型配置

系统支持多层模型配置：

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `deep_think_llm` | 深度思考模型 | gpt-4o |
| `quick_think_llm` | 快速思考模型 | gpt-4o-mini |
| `mid_think_llm` | 中等思考模型 | gpt-4o |
| `ultra_think_llm` | 超深度思考模型 | gpt-4o |
| `backend_url` | API 端点 | https://api.openai.com/v1 |

支持通过环境变量或前端设置页切换模型厂商。

## API 接口

后端 FastAPI 提供以下主要接口：

- `POST /api/analyze` — 启动分析任务
- `GET /api/analysis/{id}` — 获取分析结果
- `GET /api/holdings` — 获取持仓
- `POST /api/watchlist` — 管理自选股
- `GET /api/reports` — 历史研报
- `POST /api/scheduler` — 定时任务管理

## 0. 自动领取规则与当前队列

### 状态规则

- `ready`：允许 `scripts/auto_dev_loop.sh` 自动领取。
- `in_progress`：已有 OpenCode/OpenClaw/Codex 半成品或人工正在处理，自动开发不得重复领取。
- `blocked`：前置任务、人工确认、权限或成本条件未满足。
- `done`：已完成并有 commit / 验收记录。
- `proposed`：候选任务草案，只能人工或 Codex 确认后转为 `ready`。

### 自动领取顺序

1. 自动脚本只领取 `状态=ready` 的任务。

3. 工作区不干净时必须停止，先进入人工/Codex review，不允许覆盖半成品。
4. 每个任务必须写入 `docs/task_runs/<TASK_ID>-YYYYMMDD-HHMMSS/` 运行档案。
5. 通过任务必须同时更新 `docs/TASKS.md`、`docs/DEVLOG.md`。

# 架构决策记录

## ADR-001: 采用 LangGraph 编排多智能体
- **日期**：项目初始化
- **背景**：需要 14 个 Agent 按特定流程协作，有循环（辩论）和条件分支
- **决策**：使用 LangGraph 状态图编排，而非简单的链式调用
- **原因**：LangGraph 原生支持循环、条件路由、状态管理，适合辩论机制
- **影响**：所有 Agent 间通信通过 Graph State 传递，新增 Agent 需要注册到图中

## ADR-002: 多模型厂商适配层
- **日期**：项目初始化
- **背景**：不同 Agent 对模型能力需求不同，用户可能有不同的模型偏好
- **决策**：通过 `llm_clients/` 统一适配，支持通过配置切换厂商和模型
- **原因**：避免硬编码单一厂商，降低用户使用门槛
- **影响**：新增模型厂商需要在 `llm_clients/` 中添加适配器

## ADR-003: SQLite 作为持久化方案
- **日期**：项目初始化
- **背景**：需要存储研报、自选股、定时任务等结构化数据
- **决策**：使用 SQLite，单文件部署，无需额外数据库服务
- **原因**：本地部署场景，轻量级，零运维
- **影响**：并发写入有限，定时任务和分析任务需要串行化写入

## ADR-004: OpenClaw 作为项目协作调度层
- **日期**：2026-05-09
- **背景**：需要 OpenClaw、OpenCode、OpenCode TUI 三者协作处理同一项目
- **决策**：OpenClaw 负责任务判断和调度，不直接做代码修改；OpenCode 负责代码执行；OpenCode TUI 负责审查
- **原因**：OpenClaw 有完整的 agent 调度能力（exec / sessions_spawn / cron），适合做编排层
- **影响**：所有代码修改任务必须经过 OpenClaw 判断复杂度后决定执行路径

## ADR-005: Git 仓库 + docs/ 作为项目事实源
- **日期**：2026-05-09
- **背景**：多个工具需要读取同一套项目上下文
- **决策**：不使用任何 agent 的独立记忆系统保存项目状态，所有关键信息写入 Git 仓库的 docs/ 目录
- **原因**：避免信息分散、版本冲突、单点失效
- **影响**：每次任务开始前必须读取 AGENTS.md + docs/ 下的上下文文件

+def parse_review_meta_for_run(run_dir: Path) -> list[dict[str, object]]:
+    """Parse all ``review-meta-roundN.json`` files in a single run directory.

+    Returns a list sorted by round number. Each entry augments the raw JSON

+def _fmt_ms(ms: int | float) -> str:
+    """Render milliseconds as a compact human-readable duration."""
+    try:

+    if ms_int < 1000:
+        return f"{ms_int}ms"

+    if seconds < 60:
+        return f"{seconds:.1f}s"
+    minutes = seconds / 60.0
+    if minutes < 60:
+        return f"{minutes:.1f}m"
+    hours = minutes / 60.0
+    return f"{hours:.2f}h"

        # The P0 callout must appear; if it doesn't, the closeout is broken.
        assert "P0" in section

    def test_partial_output_recorded_even_on_timeout(self):
        """A timeout with partial output must mark has_partial_output=True
        so the human recovery path knows there's salvageable content."""

             "status": "TIMEOUT", "elapsed_ms": 600000,
             "timeout_seconds": 1200, "exit_code": 124, "timed_out": True,

             "parse_error": False},
        ]
        summary = summarize_review_meta(entries)

   902	# metadata in the nightly report. The watchdog records a ``review-meta-roundN.json``
   903	# next to every codex-review-roundN.txt in docs/task_runs/<run>/, even when the
   904	# review times out or is skipped. This block aggregates those JSON files and
   905	# renders a compact section so operators can answer at a glance:
   906	#   - Did any review hit the watchdog?
   907	#   - How long did reviews actually take vs the configured timeout?

   911	#   - Read-only: only reads review-meta-round*.json from existing run archives.
   912	#   - Never marks a timeout as PASS — the JSON status is taken verbatim.

   920	def _safe_read_json(path: Path) -> Optional[dict[str, object]]:
   921	    """Read a JSON file, returning None on any read/parse failure."""
   922	    try:
   923	        return json.loads(path.read_text(encoding="utf-8"))
   924	    except (OSError, ValueError):
   925	        return None

   928	def parse_review_meta_for_run(run_dir: Path) -> list[dict[str, object]]:
   929	    """Parse all ``review-meta-roundN.json`` files in a single run directory.
   930	
   931	    Returns a list sorted by round number. Each entry augments the raw JSON
   932	    with ``run_id`` and ``meta_path`` so the report can reference the source.
   933	    Corrupt or missing files produce no entries (and never raise).
   934	    """
   935	    if not run_dir.exists():
   936	        return []
   937	
   938	    entries: list[dict[str, object]] = []
   939	    for f in sorted(run_dir.iterdir()):
   940	        m = _REVIEW_META_FILENAME_RE.match(f.name)
   941	        if not m:
   942	            continue
   943	        data = _safe_read_json(f)
   944	        if not isinstance(data, dict):
   945	            # Record the parse failure so the report can flag the corruption
   946	            # instead of silently hiding a possible timeout.
   947	            entries.append({
   948	                "run_id": run_dir.name,
   949	                "round": int(m.group(1)),
   950	                "meta_path": str(f),
   951	                "parse_error": True,
   952	            })
   953	            continue
   954	        data.setdefault("run_id", run_dir.name)
   955	        data.setdefault("meta_path", str(f))
   956	        data["parse_error"] = False
   957	        entries.append(data)
   958	
   959	    entries.sort(key=lambda d: int(d.get("round", 0) or 0))
   960	    return entries

   963	def collect_review_meta(
   964	    task_runs_dir: Path, target_date: Optional[str] = None
   965	) -> list[dict[str, object]]:
   966	    """Aggregate review-meta-roundN.json across all (or date-filtered) runs.
   967	
   968	    Each entry mirrors :func:`parse_review_meta_for_run` and additionally
   969	    carries ``task_id`` and ``priority`` when the corresponding run has a
   970	    parseable task.md.
   971	    """
   972	    if not task_runs_dir.exists():
   973	        return []
   974	
   975	    all_entries: list[dict[str, object]] = []
   976	    for d in sorted(task_runs_dir.iterdir()):
   977	        if not d.is_dir():
   978	            continue
   979	        # Date filter (mirror scan_task_runs' timestamp extraction)
   980	        if target_date:
   981	            parts = d.name.split("-")
   982	            date_part = None
   983	            for i, p in enumerate(parts):
   984	                if (
   985	                    re.match(r"^\d{8}$", p)
   986	                    and i + 1 < len(parts)
   987	                    and re.match(r"^\d{6}$", parts[i + 1])
   988	                ):
   989	                    date_part = f"{p[:4]}-{p[4:6]}-{p[6:8]}"
   990	                    break
   991	            if date_part != target_date:
   992	                continue
   993	
   994	        run_entries = parse_review_meta_for_run(d)
   995	        if not run_entries:
   996	            continue
   997	
   998	        # Annotate each entry with task_id / priority parsed from task.md so
   999	        # the report can join review timing back to the originating task.
  1000	        task_meta = parse_task_md(d / "task.md")
  1001	        task_id_raw = task_meta.get("task", "")
  1002	        task_id = task_id_raw
  1003	        m = re.match(r"^([A-Z]+-[\w-]+)\s*-\s*(.+)$", task_id_raw)
  1004	        if m:
  1005	            task_id = m.group(1).strip()
  1006	        priority = task_meta.get("priority", "")
  1007	
  1008	        for entry in run_entries:
  1009	            entry.setdefault("task_id", task_id)
  1010	            entry.setdefault("priority", priority)
  1011	            all_entries.append(entry)
  1012	
  1013	    return all_entries

  1016	def summarize_review_meta(
  1017	    entries: list[dict[str, object]],
  1018	) -> dict[str, object]:
  1019	    """Compute aggregate review-watchdog stats from raw meta entries.
  1020	
  1021	    Returns:
  1022	      - count: total review entries
  1023	      - pass_count / fail_count / timeout_count / skipped_count
  1024	      - max_elapsed_ms / avg_elapsed_ms
  1025	      - any_timed_out: bool
  1026	      - any_partial_output: bool
  1027	      - parse_errors: int — corrupt meta files that could not be decoded
  1028	      - by_task: dict[task_id] -> {count, max_elapsed_ms, any_timed_out}
  1029	    """
  1030	    if not entries:
  1031	        return {
  1032	            "count": 0,
  1033	            "pass_count": 0,
  1034	            "fail_count": 0,
  1035	            "timeout_count": 0,
  1036	            "skipped_count": 0,
  1037	            "max_elapsed_ms": 0,
  1038	            "avg_elapsed_ms": 0.0,
  1039	            "any_timed_out": False,
  1040	            "any_partial_output": False,
  1041	            "parse_errors": 0,
  1042	            "by_task": {},
  1043	        }
  1044	
  1045	    pass_c = 0
  1046	    fail_c = 0
  1047	    timeout_c = 0
  1048	    skipped_c = 0
  1049	    parse_errors = 0
  1050	    elapsed_samples: list[int] = []
  1051	    any_timeout = False
  1052	    any_partial = False
  1053	    by_task: dict[str, dict[str, object]] = {}
  1054	
  1055	    for e in entries:
  1056	        if e.get("parse_error"):
  1057	            parse_errors += 1
  1058	            continue
  1059	        status = str(e.get("status", "")).upper()
  1060	        if status == "PASS":
  1061	            pass_c += 1
  1062	        elif status == "TIMEOUT":
  1063	            timeout_c += 1
  1064	            any_timeout = True
  1065	        elif status == "SKIPPED":
  1066	            skipped_c += 1
  1067	        elif status == "FAIL":
  1068	            fail_c += 1
  1069	        if bool(e.get("has_partial_output", False)):
  1070	            any_partial = True
  1071	        elapsed = int(e.get("elapsed_ms", 0) or 0)
  1072	        if elapsed > 0:
  1073	            elapsed_samples.append(elapsed)
  1074	        # Per-task aggregation
  1075	        tid = str(e.get("task_id", "") or "?")
  1076	        bucket = by_task.setdefault(tid, {
  1077	            "count": 0,
  1078	            "max_elapsed_ms": 0,
  1079	            "any_timed_out": False,
  1080	            "any_partial": False,
  1081	            "statuses": [],
  1082	        })
  1083	        bucket["count"] = int(bucket["count"]) + 1  # type: ignore[operator]
  1084	        if elapsed > int(bucket["max_elapsed_ms"] or 0):  # type: ignore[arg-type]
  1085	            bucket["max_elapsed_ms"] = elapsed
  1086	        if any_timeout and tid == str(e.get("task_id", "")):
  1087	            bucket["any_timed_out"] = bool(bucket.get("any_timed_out")) or bool(
  1088	                e.get("timed_out", False)
  1089	            )
  1090	        if bool(e.get("timed_out", False)):
  1091	            bucket["any_timed_out"] = True  # type: ignore[assignment]
  1092	        if bool(e.get("has_partial_output", False)):
  1093	            bucket["any_partial"] = True  # type: ignore[assignment]
  1094	        bucket["statuses"].append(status)  # type: ignore[union-attr]
  1095	
  1096	    max_elapsed = max(elapsed_samples) if elapsed_samples else 0
  1097	    avg_elapsed = (
  1098	        sum(elapsed_samples) / len(elapsed_samples) if elapsed_samples else 0.0
  1099	    )
  1100	
  1101	    return {
  1102	        "count": len(entries),
  1103	        "pass_count": pass_c,
  1104	        "fail_count": fail_c,
  1105	        "timeout_count": timeout_c,
  1106	        "skipped_count": skipped_c,
  1107	        "max_elapsed_ms": max_elapsed,
  1108	        "avg_elapsed_ms": avg_elapsed,
  1109	        "any_timed_out": any_timeout,
  1110	        "any_partial_output": any_partial,
  1111	        "parse_errors": parse_errors,
  1112	        "by_task": by_task,
  1113	    }

  1116	def _fmt_ms(ms: int | float) -> str:
  1117	    """Render milliseconds as a compact human-readable duration."""
  1118	    try:
  1119	        ms_int = int(ms)
  1120	    except (TypeError, ValueError):
  1121	        return "0s"
  1122	    if ms_int <= 0:
  1123	        return "0s"
  1124	    if ms_int < 1000:
  1125	        return f"{ms_int}ms"
  1126	    seconds = ms_int / 1000.0
  1127	    if seconds < 60:
  1128	        return f"{seconds:.1f}s"
  1129	    minutes = seconds / 60.0
  1130	    if minutes < 60:
  1131	        return f"{minutes:.1f}m"
  1132	    hours = minutes / 60.0
  1133	    return f"{hours:.2f}h"

  1270	    """Parse test result counts from trace files in a task run.

  1293	                if sm:

  1295	                em = re.search(r"(\d+) error", line)
  1296	                if em:
  1297	                    summary["errors"] = int(em.group(1))
  1298	                summary["raw_line"] = line
  1299	                return summary

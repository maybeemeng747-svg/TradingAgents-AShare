# 项目说明

## 项目定位

TradingAgents-AShare 是一个面向 A 股投资者的多智能体投研系统，核心理念：

- **模拟真实投研机构**：14 个专业角色分工协作
- **多空辩论机制**：多头研究员 vs 空头研究员，研究总监裁决
- **多模型厂商支持**：OpenAI / Anthropic / Google / 智谱 / DeepSeek / 小米等
- **意图驱动交互**：自然语言输入，自动识别标的和周期
- **持仓追踪**：导入持仓，自动跟踪，连续分析

## 当前产品事实（2026-07-10）

项目已从单一报告生成器扩展为分层投研工作台，但产品主线应保持收敛：

```text
Tree Work 既有研报/半年报知识页（历史上游）
  -> ZCode 知识库接入、研究评分与快照发布
  -> 来源与事实审计
  -> 昊天左侧候选
  -> TradeFlow 少量候选池
  -> 轻量 TA / 人工确认的完整 TA
  -> 观察仓、盘中观察、盘后复盘
```

TradeFlow 的 `TECH_TRADE` 与 `POLICY_AMBUSH/POLICY_CONFIRM` 必须分池展示，不能把短线技术机会当作中长期昊天候选。Fast Radar、Light Research、Full TA 的运行层级也必须保持清晰：完整 TA 只能人工确认触发。

现有 Tree Work 知识页只作为可追溯的历史上游与背景/观点证据；后续知识库接入、`research-scorer` 和正式快照发布统一由 ZCode 负责。公告、原始财报和行情数据仍是事实与动作门禁的优先来源。所有知识命中都必须带来源路径、报告期或更新时间、来源等级和新鲜度。

## 核心架构

### 1. 分析师团队（7 个）

| 角色 | 职责 | 数据源 |
|------|------|--------|
| 基本面分析师 | 财务指标、估值分析 | AKShare/BaoStock |
| 情绪分析师 | 社交媒体情绪、舆情 | AKShare |
| 新闻分析师 | 新闻事件、政策影响 | AKShare |
| 技术分析师 | K线形态、技术指标 | AKShare/BaoStock |
| 宏观分析师 | 宏观经济、利率环境 | AKShare |
| 主力资金分析师 | 大单流向、主力动向 | AKShare |
| 量价分析师 | 成交量、量价关系 | AKShare/BaoStock |

### 2. 研究员团队

- **多头研究员**：综合分析师结论，构建看多 Claim
- **空头研究员**：综合分析师结论，构建看空 Claim
- **研究总监**：裁决多空辩论，形成投资计划

### 3. 风控团队

- **风控经理**：评估风险、设置止损止盈
- **合规检查**：确保建议符合投资规范

### 4. 交易员

- 根据研究计划和风控要求，输出最终交易建议

### 5. 编排层

- **LangGraph**：状态图编排，控制 Agent 间信息流转
- **辩论机制**：多轮辩论，每轮有 Claim → Counter-Claim → 裁决

## 数据流

```
用户输入（自然语言）
  ↓
意图识别 → 标的 + 周期
  ↓
数据获取（7 路并行）
  ↓
分析师团队（7 个并行分析）
  ↓
研究员辩论（多轮）
  ↓
风控评估
  ↓
交易建议输出
  ↓
研报存储 + 通知推送
```

## 模型配置

系统支持多层模型配置：

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `deep_think_llm` | 深度思考模型 | gpt-4o |
| `quick_think_llm` | 快速思考模型 | gpt-4o-mini |
| `mid_think_llm` | 中等思考模型 | gpt-4o |
| `ultra_think_llm` | 超深度思考模型 | gpt-4o |
| `backend_url` | API 端点 | https://api.openai.com/v1 |

支持通过环境变量或前端设置页切换模型厂商。

## API 接口

后端 FastAPI 提供以下主要接口：

- `POST /api/analyze` — 启动分析任务
- `GET /api/analysis/{id}` — 获取分析结果
- `GET /api/holdings` — 获取持仓
- `POST /api/watchlist` — 管理自选股
- `GET /api/reports` — 历史研报
- `POST /api/scheduler` — 定时任务管理

## 前端功能

- 意图驱动的自然语言交互
- 辩论对战可视化（多空对抗 Drawer）
- 持仓追踪与跟踪看板
- 结构化研报管理
- 定时分析配置
- 模型厂商设置

#### FUND-003A-B 补修验收口径

- 证据的 `direction`/`negation`/因果关系必须属于具体术语及其出现位置，禁止挂在整条 entry 上被其他指标复用。

- 必测对抗样例：中性首次出现+后文上涨；`未采用净额法，仍采用总额法`；`原材料下降+合同负债增加`；同指标多条相反声明；多术语长证据片段。

# 架构决策记录

## ADR-001: 采用 LangGraph 编排多智能体
- **日期**：项目初始化
- **背景**：需要 14 个 Agent 按特定流程协作，有循环（辩论）和条件分支
- **决策**：使用 LangGraph 状态图编排，而非简单的链式调用
- **原因**：LangGraph 原生支持循环、条件路由、状态管理，适合辩论机制
- **影响**：所有 Agent 间通信通过 Graph State 传递，新增 Agent 需要注册到图中

## ADR-002: 多模型厂商适配层
- **日期**：项目初始化
- **背景**：不同 Agent 对模型能力需求不同，用户可能有不同的模型偏好
- **决策**：通过 `llm_clients/` 统一适配，支持通过配置切换厂商和模型
- **原因**：避免硬编码单一厂商，降低用户使用门槛
- **影响**：新增模型厂商需要在 `llm_clients/` 中添加适配器

## ADR-003: SQLite 作为持久化方案
- **日期**：项目初始化
- **背景**：需要存储研报、自选股、定时任务等结构化数据
- **决策**：使用 SQLite，单文件部署，无需额外数据库服务
- **原因**：本地部署场景，轻量级，零运维
- **影响**：并发写入有限，定时任务和分析任务需要串行化写入

## ADR-004: OpenClaw 作为项目协作调度层
- **日期**：2026-05-09
- **背景**：需要 OpenClaw、OpenCode、OpenCode TUI 三者协作处理同一项目
- **决策**：OpenClaw 负责任务判断和调度，不直接做代码修改；OpenCode 负责代码执行；OpenCode TUI 负责审查
- **原因**：OpenClaw 有完整的 agent 调度能力（exec / sessions_spawn / cron），适合做编排层
- **影响**：所有代码修改任务必须经过 OpenClaw 判断复杂度后决定执行路径

## ADR-005: Git 仓库 + docs/ 作为项目事实源
- **日期**：2026-05-09
- **背景**：多个工具需要读取同一套项目上下文
- **决策**：不使用任何 agent 的独立记忆系统保存项目状态，所有关键信息写入 Git 仓库的 docs/ 目录
- **原因**：避免信息分散、版本冲突、单点失效
- **影响**：每次任务开始前必须读取 AGENTS.md + docs/ 下的上下文文件

## ADR-006: 2026-07-10 将研报/半年报/昊天闭环设为唯一产品主线
- **日期**：2026-07-10
- **背景**：系统已有 TradeFlow、跟踪看板、知识库和自动开发等大量工程能力，但真实候选中仍以技术池为主，观察仓和盘后 Review 的生产记录不足，半年报事实 Provider 尚未完成。
- **决策**：优先完成 HY-002/HY-003/KB-015 及其后续事实审计，再做昊天真实候选和交易日回放；PLAYBOOK-002~006 暂停，除非直接阻塞主线。
- **原因**：用户核心目标是从政策、产业和研报中找到少量高质量中长期候选，而不是继续扩大功能数量。先验证选股和证据闭环，才能判断后续仓位规则是否值得实现。
- **影响**：自动领取顺序以 `docs/TASKS.md` 的“当前执行队列”为准；fixture 验收和真实运行验收必须分开记录；新功能必须说明是否直接服务主线。

## ADR-007: 研究评分采用四卡分层所有权，不生成混合总分
- **日期**：2026-07-13
- **背景**：现有 Tree Work 知识库、TA readiness、TradeFlow 候选分、账户风控和 PLAYBOOK 已分别存在评分或阶段字段。若各层都计算完整总分和动作，会产生重复计分、阈值冲突，以及“好公司被误判为现在可以买”的风险。
- **决策**：`research-scorer` 的代码、规则版本和正式快照写入归 ZCode 知识库接入项目所有；ZCode 发布的知识快照只拥有慢变量 `research_evidence_confidence` 与 `thesis_quality`。现有 Tree Work 页面继续作为上游知识输入，不要求历史改名。TradingAgents-AShare 不复刻评分公式，只读取版本化快照；TradeFlow 复用现有动态因子生成 `entry_timing`，账户上下文生成 `portfolio_fit`，TA 在四卡之后统一执行硬性否决并映射 PLAYBOOK 七阶段。禁止合成单一股票总分，禁止知识快照携带或覆盖交易动作。
- **原因**：证据可信度、公司逻辑、实时买点和账户资格回答的是四个不同问题；分层后才能做到来源可追溯、动态变化可解释，并让高研究分始终受行情、账户和风控约束。
- **影响**：知识库侧任务单独记录在 `docs/zcode_research_scorer_handoff.md`；本仓库新增 SCORE-001~006 消费与裁决任务线。`execution_action` 与 Buy/Risk Level 继续作为底层安全契约，`playbook_stage` 只提供更细语义。SCORE-005 可以实现不含仓位数量的阶段判定，但不解锁 PLAYBOOK-002/003 的真实三笔法和仓位拆分规则。SCORE-006 必须等真实 ZCode 快照人工确认后释放，fixture 不得冒充跨项目验收。

      - `regulatory_investigation`：监管立案/调查（立案调查/行政处罚/监管函/警示函）
      - `major_write_off`：大额资产减值（商誉减值/大额计提）

    - **风控优先模式**（`risk_first_mode`）：CRITICAL/HIGH 事件激活时，禁止强买入动作（建仓/买入/加仓/追涨/BUY/ENTER）。

_VERDICT_RE = re.compile(r"<!--\s*VERDICT:\s*(\{[^>]+\})\s*-->")

_DIRECTION_ALIAS = {

# ---------------------------------------------------------------------------
# Token cache (module-level singleton)

_token_cache: Dict[str, Any] = {"token": None, "expires_at": 0.0}


def _get_env(key: str, default: str = "") -> str:
    return os.getenv(key, default).strip()


def is_feishu_configured() -> bool:
    """Return True if the minimum Feishu env vars are set."""
    return bool(_get_env("FEISHU_APP_ID") and _get_env("FEISHU_APP_SECRET"))


def _fetch_tenant_access_token() -> str:
    """Obtain (and cache) a tenant_access_token."""
    now = time.time()
    if _token_cache["token"] and now < _token_cache["expires_at"]:
        return _token_cache["token"]

    url = f"{_FEISHU_BASE}/auth/v3/tenant_access_token/internal"
    resp = requests.post(url, json={
        "app_id": _get_env("FEISHU_APP_ID"),
        "app_secret": _get_env("FEISHU_APP_SECRET"),
    }, timeout=15)
    resp.raise_for_status()
    data = resp.json()
    if data.get("code") != 0:
        raise RuntimeError(f"Feishu auth failed: {data.get('msg', data)}")

    token = data["tenant_access_token"]
    _token_cache["token"] = token
    _token_cache["expires_at"] = now + _TOKEN_TTL
    return token


def _feishu_headers() -> Dict[str, str]:
    return {
        "Authorization": f"Bearer {_fetch_tenant_access_token()}",
        "Content-Type": "application/json",
    }


# ---------------------------------------------------------------------------
# Verdict extraction (reused from email_report_service pattern)
# ---------------------------------------------------------------------------

def _extract_verdict(text: str) -> Optional[Dict[str, str]]:
    m = _VERDICT_RE.search(text)
    if not m:
        return None
    try:
        parsed = json.loads(m.group(1))
        direction = parsed.get("direction", "")
        reason = parsed.get("reason", "")
        if not direction or not reason:
            return None
        direction = _DIRECTION_ALIAS.get(direction.upper(), direction)
        return {"direction": direction, "reason": reason.strip()[:80]}
    except (json.JSONDecodeError, AttributeError):
        return None


def _semantic_field(report: "ReportDB", key: str) -> Optional[str]:
    value = getattr(report, key, None)
    if value:
        return str(value)
    rd = getattr(report, "result_data", None)
    if isinstance(rd, dict):
        value = rd.get(key)
        if value:
            return str(value)
    return None

def render_report_markdown(report: "ReportDB") -> str:
    """Render a *ReportDB* instance as a Feishu-friendly Markdown document.

    The Markdown is later uploaded via the DocX raw content API so it must
    use Feishu-compatible syntax (standard GFM mostly works).
    """
    symbol = report.symbol or ""
    trade_date = report.trade_date or ""
    direction = _semantic_field(report, "research_direction") or report.direction or ""
    action = _semantic_field(report, "action_label") or report.decision or ""
    execution_action = _semantic_field(report, "execution_action") or ""
    confidence = report.confidence
    target_price = report.target_price
    stop_loss = report.stop_loss_price

    parts: list[str] = []

    # ── Title ──
    parts.append(f"# TradingAgents 投研报告 — {symbol} ({trade_date})\n")

    # ── Summary table ──
    parts.append("| 项目 | 详情 |")
    parts.append("| --- | --- |")
    parts.append(f"| **标的** | {symbol} |")
    parts.append(f"| **日期** | {trade_date} |")
    if direction:
        parts.append(f"| **方向** | {direction} |")
    if action:
        parts.append(f"| **动作** | {action} |")
    if execution_action:
        parts.append(f"| **执行动作** | {execution_action} |")
    if confidence is not None:
        parts.append(f"| **置信度** | {confidence}% |")
    if target_price is not None:
        parts.append(f"| **目标价** | ¥{target_price:.2f} |")
    if stop_loss is not None:
        parts.append(f"| **止损价** | ¥{stop_loss:.2f} |")
    parts.append("")

    # ── Agent verdicts ──
    verdicts: list[tuple[str, Dict[str, str]]] = []
    for attr, title in _AGENT_SECTIONS:
        content = getattr(report, attr, None)
        if content is None:
            continue
        v = _extract_verdict(content)
        if v:
            verdicts.append((title, v))

    if verdicts:
        parts.append("## 各方观点\n")
        for title, v in verdicts:
            parts.append(f"- **{title}**：{v['direction']} — {v['reason']}")
        parts.append("")

    # ── Key metrics ──
    key_metrics: Optional[List[dict]] = getattr(report, "key_metrics", None)
    if key_metrics:
        parts.append("## 关键指标\n")
        parts.append("| 指标 | 数值 | 状态 |")
        parts.append("| --- | --- | --- |")
        status_label = {"good": "良好", "neutral": "中性", "bad": "不佳"}
        for item in key_metrics:
            name = item.get("name", "")
            value = item.get("value", "")
            status = status_label.get(item.get("status", ""), item.get("status", ""))
            parts.append(f"| {name} | {value} | {status} |")
        parts.append("")

    # ── Risk items ──
    risk_items: Optional[List[dict]] = getattr(report, "risk_items", None)
    if risk_items:
        parts.append("## 风险提示\n")
        for item in risk_items:
            name = item.get("name", "")
            level = _RISK_LEVEL_LABEL.get(item.get("level", ""), item.get("level", ""))
            desc = item.get("description", "")
            parts.append(f"- **[{level}]** {name}：{desc}")
        parts.append("")

    # ── Final trade decision ──
    ftd = getattr(report, "final_trade_decision", None)
    if ftd:
        parts.append("## 最终交易决策\n")
        parts.append(ftd)
        parts.append("")

    # ── Investment plan ──
    ip = getattr(report, "investment_plan", None)
    if ip:
        parts.append("## 投资计划\n")
        parts.append(ip)
        parts.append("")

    # ── Trader investment plan ──
    tip = getattr(report, "trader_investment_plan", None)
    if tip:
        parts.append("## 交易员计划\n")
        parts.append(tip)
        parts.append("")

    # ── Local knowledge block (KB-003) ──
    rd = getattr(report, "result_data", None)
    if isinstance(rd, dict):
        lk = rd.get("local_knowledge_block")
        if lk:
            parts.append("## 本地知识补充\n")
            parts.append(str(lk))
            parts.append("")

        # ── Half-year facts block (HY-004) ──
        hy = rd.get("half_year_facts_block")

   277	def _create_document(title: str, folder_token: Optional[str] = None) -> Dict[str, str]:
   278	    """Create an empty Feishu document and return {document_id, url}."""
   279	    url = f"{_FEISHU_BASE}/docx/v1/documents"
   280	    body: Dict[str, Any] = {"title": title}
   281	    if folder_token:
   282	        body["folder_token"] = folder_token
   283	
   284	    resp = requests.post(url, headers=_feishu_headers(), json=body, timeout=30)
   285	    resp.raise_for_status()
   286	    data = resp.json()
   287	    if data.get("code") != 0:
   288	        raise RuntimeError(f"Feishu create document failed: {data.get('msg', data)}")
   289	
   290	    doc = data["data"]["document"]
   291	    return {
   292	        "document_id": doc["document_id"],
   293	        "url": f"https://feishu.cn/docx/{doc['document_id']}",
   294	    }

   298	    """Retrieve the block list of a document (page block + children)."""
   299	    url = f"{_FEISHU_BASE}/docx/v1/documents/{document_id}/blocks"
   300	    resp = requests.get(url, headers=_feishu_headers(), timeout=30)
   301	    resp.raise_for_status()
   302	    data = resp.json()
   303	    if data.get("code") != 0:
   304	        raise RuntimeError(f"Feishu get blocks failed: {data.get('msg', data)}")
   305	    return data["data"]["items"]

   309	    document_id: str,
   310	    parent_block_id: str,
   311	    children: List[Dict[str, Any]],

   313	) -> None:
   314	    """Append block children under *parent_block_id*."""
   315	    url = f"{_FEISHU_BASE}/docx/v1/documents/{document_id}/blocks/{parent_block_id}/children"
   316	    body: Dict[str, Any] = {"children": children}

   330	def _text_element(content: str, bold: bool = False) -> Dict[str, Any]:
   331	    """Build a single text element for a block."""
   332	    style: Dict[str, Any] = {}
   333	    if bold:
   334	        style["bold"] = True
   335	    elem: Dict[str, Any] = {
   336	        "text_run": {
   337	            "content": content,
   338	        }
   339	    }
   340	    if style:
   341	        elem["text_run"]["text_element_style"] = style
   342	    return elem

   345	def _heading_block(level: int, text: str) -> Dict[str, Any]:
   346	    """Build a heading block (level 2-9 → Feishu heading2-heading9)."""
   347	    block_type = level + 1  # Feishu: 3=heading1, 4=heading2, ...
   348	    return {
   349	        "block_type": block_type,
   350	        "heading": {  # generic key; Feishu uses heading2..heading9 per level
   351	            "elements": [_text_element(text)],
   352	        },
   353	    }

   356	def _paragraph_block(elements: List[Dict[str, Any]]) -> Dict[str, Any]:
   357	    return {
   358	        "block_type": 2,
   359	        "text": {"elements": elements},
   360	    }

   395	def markdown_to_blocks(md: str) -> List[Dict[str, Any]]:
   396	    """Convert a subset of Markdown to Feishu document blocks.
   397	
   398	    Supports: headings (#), bold (**), bullet lists (- / *), ordered lists (1.),
   399	    horizontal rules (---), and plain paragraphs.
   400	    """
   401	    blocks: List[Dict[str, Any]] = []
   402	    lines = md.split("\n")
   403	    i = 0
   404	    while i < len(lines):
   405	        line = lines[i]
   406	        stripped = line.strip()
   407	
   408	        # Skip empty lines
   409	        if not stripped:
   410	            i += 1
   411	            continue
   412	
   413	        # Horizontal rule
   414	        if stripped in ("---", "***", "___"):
   415	            blocks.append(_divider_block())
   416	            i += 1
   417	            continue
   418	
   419	        # Headings
   420	        heading_match = re.match(r"^(#{1,9})\s+(.+)$", stripped)
   421	        if heading_match:
   422	            level = len(heading_match.group(1))
   423	            text = heading_match.group(2).strip()
   424	            if level == 1:
   425	                # H1 → heading1 (block_type 3)
   426	                blocks.append({
   427	                    "block_type": 3,
   428	                    "heading1": {"elements": [_text_element(text)]},
   429	                })
   430	            elif level == 2:
   431	                blocks.append({
   432	                    "block_type": 4,
   433	                    "heading2": {"elements": [_text_element(text)]},
   434	                })
   435	            elif level == 3:
   436	                blocks.append({
   437	                    "block_type": 5,
   438	                    "heading3": {"elements": [_text_element(text)]},
   439	                })
   440	            else:
   441	                # heading4+ uses block_type = level + 1
   442	                key = f"heading{level}"
   443	                blocks.append({
   444	                    "block_type": level + 1,
   445	                    key: {"elements": [_text_element(text)]},
   446	                })
   447	            i += 1
   448	            continue
   449	
   450	        # Bullet list
   451	        if re.match(r"^[-*]\s+", stripped):
   452	            text = re.sub(r"^[-*]\s+", "", stripped)
   453	            blocks.append(_bullet_block(_parse_inline(text)))
   454	            i += 1
   455	            continue
   456	
   457	        # Ordered list
   458	        ol_match = re.match(r"^\d+\.\s+", stripped)
   459	        if ol_match:
   460	            text = re.sub(r"^\d+\.\s+", "", stripped)
   461	            blocks.append(_ordered_block(_parse_inline(text)))
   462	            i += 1
   463	            continue
   464	
   465	        # Table: collect contiguous table lines and convert to a code block
   466	        # (Feishu block API tables are complex; render as a readable code block)
   467	        if "|" in stripped and stripped.startswith("|"):
   468	            table_lines: list[str] = []
   469	            while i < len(lines) and "|" in lines[i].strip():
   470	                table_lines.append(lines[i])
   471	                i += 1
   472	            # Render as a paragraph with each row on its own line, escaping pipes
   473	            for tl in table_lines:
   474	                cells = [c.strip() for c in tl.strip().strip("|").split("|")]
   475	                # Skip separator rows
   476	                if all(set(c) <= {"-", ":", " "} for c in cells):
   477	                    continue
   478	                blocks.append(_paragraph_block([_text_element(" | ".join(cells))]))
   479	            continue
   480	
   481	        # Default: paragraph
   482	        blocks.append(_paragraph_block(_parse_inline(stripped)))
   483	        i += 1
   484	
   485	    return blocks

   492	def export_report_to_feishu(report: "ReportDB") -> Dict[str, Any]:
   493	    """Export a report to a Feishu cloud document.
   494	
   495	    Returns::

   497	        {

   514	    symbol = report.symbol or "未知"
   515	    trade_date = report.trade_date or ""
   516	    direction = _semantic_field(report, "research_direction") or report.direction or ""
   517	    title = f"TradingAgents {symbol} {trade_date} {direction}".strip()
   518	
   519	    try:
   520	        # 1. Create empty document
   521	        folder_token = _get_env("FEISHU_FOLDER_TOKEN") or None
   522	        doc_info = _create_document(title, folder_token)
   523	        document_id = doc_info["document_id"]
   524	
   525	        # 2. Render markdown
   526	        md = render_report_markdown(report)
   527	
   528	        # 3. Convert to blocks and insert
   529	        blocks = markdown_to_blocks(md)
   530	        if blocks:
   531	            # The page block is the first block returned by get_blocks
   532	            page_blocks = _get_document_blocks(document_id)
   533	            page_block_id = page_blocks[0]["block_id"] if page_blocks else document_id
   534	            # Feishu API has a limit of ~50 children per batch
   535	            for chunk_start in range(0, len(blocks), 50):
   536	                chunk = blocks[chunk_start : chunk_start + 50]
   537	                _batch_create_blocks(document_id, page_block_id, chunk)
   538	
   539	        return {

   541	            "document_url": doc_info["url"],
   542	            "document_token": document_id,

   545	    except requests.RequestException as exc:

   551	    except Exception as exc:

def get_latest_reports_by_symbols(
    db: Session,
    symbols: List[str],
    user_id: Optional[str] = None,
) -> List[ReportDB]:
    normalized_symbols = [str(symbol).strip().upper() for symbol in symbols if str(symbol).strip()]
    if not normalized_symbols:
        return []

    query = db.query(ReportDB).options(load_only(*REPORT_SUMMARY_COLUMNS))
    if user_id:
        query = query.filter(ReportDB.user_id == user_id)

    rows = (
        query.filter(ReportDB.symbol.in_(normalized_symbols))
        .order_by(ReportDB.symbol.asc(), ReportDB.created_at.desc())
        .all()
    )

    latest_by_symbol: dict[str, ReportDB] = {}
    for row in rows:
        symbol = str(row.symbol or "").upper()
        if symbol and symbol not in latest_by_symbol:
            latest_by_symbol[symbol] = row

    return [
        normalize_report_action_label(latest_by_symbol[symbol])
        for symbol in normalized_symbols
        if symbol in latest_by_symbol
    ]

def _infer_frontend_url() -> str:
    """Infer frontend URL from FRONTEND_URL or CORS_ALLOW_ORIGINS.

    Priority: FRONTEND_URL env > first non-localhost CORS origin > first CORS origin > "".
    """
    explicit = os.getenv("FRONTEND_URL", "").strip()
    if explicit:
        return explicit
    raw = os.getenv("CORS_ALLOW_ORIGINS", "").strip()
    if not raw:
        return ""
    origins = [o.strip() for o in raw.split(",") if o.strip()]
    # Prefer non-localhost origin (production URL)
    for o in origins:
        if "localhost" not in o and "127.0.0.1" not in o:
            return o
    return origins[0] if origins else ""

def _extract_verdict(text: str) -> Optional[dict]:
    """Extract structured verdict from agent report HTML comment.

    Returns {"direction": "看多", "reason": "..."} or None.
    """
    m = _VERDICT_RE.search(text)
    if not m:
        return None
    try:
        parsed = json.loads(m.group(1))
        direction = parsed.get("direction", "")
        reason = parsed.get("reason", "")
        if not direction or not reason:
            return None
        direction = _DIRECTION_ALIAS.get(direction.upper(), direction)
        return {"direction": direction, "reason": reason.strip()[:42]}
    except (json.JSONDecodeError, AttributeError):
        return None

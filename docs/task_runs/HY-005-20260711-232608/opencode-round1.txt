### Key Logic
The module compares old research report opinions (KB-015 `ResearchFactOpinionIndexResult`) against half-year report facts (HY-003 `HalfYearFactsQueryResult`) using rules-based direction+amplitude comparison:

- **Opinion collection**: gathers `research_claims`, `forecast_items`, and `reported_facts` with directional keywords (filters out pure fact declarations)
- **Direction comparison**: positive/negative keywords + `+X%`/`-X%` parsing → `contradicted` (opposite), `weakened` (same direction but amplitude <50% expected), `supported` (same direction), or `insufficient_data` (no matching fact)
- **Segment matching**: keyword-based segment topic extraction + segment_facts lookup
- **Risk confirmation**: risk opinions checked against fact `risk_factors` list
- **Aggregation**: `contradicted > weakened > supported > insufficient_data`
- **KB-007 linkage**: `priority_reminder=True` when attention_score ≥ 1.0 AND thesis status is contradicted/weakened
- Each flag carries `evidence_level` (strong/moderate/weak/none) — single metric changes don't blow up into "logic destruction"

# E-006~E-009 修复任务（2026-05-14）

## 来源
002138 顺络电子分析报告审查发现的问题，前序 D/E 系列已大部分落地。

---

## E-006 raw_evidence 持久化丢失
**优先级：P0**
**问题：** E-004 的 raw_evidence 在图运行中有，但 API 保存报告时被丢弃，`result_data.short_term.metadata` 里只有评分字段，没有 raw_evidence。
**修复：** 在报告持久化链路中，确保 `metadata.raw_evidence` 写入 `result_data`。排查 `api/services/report_service.py` 或相关保存逻辑，找到丢弃点并保留该字段。

## E-007 LHB 触发链路透明化
**优先级：P1**
**问题：** 资金异动明显的票（如002138），报告里没有龙虎榜原始数据，也没有 `force=True/False` 的痕迹，看不出 LHB 是否被触发。
**修复：** 
- 资金异动触发 LHB 查询时，报告必须展示 `force=True` 后的龙虎榜查询结果或明确失败原因
- 未触发时也要标注"未触发原因"（如资金流未超阈值）

## E-008 执行质检区间提取优先级
**优先级：P1**
**问题：** 风控最终有效建仓区间是 `35.80-36.20`，但执行质检提取成了上游废弃区间 `35.50-36.50`，导致 Strong Gate 报"执行层字段冲突"（不是误报）。
**修复：** 执行质检提取区间时，优先提取"唯一有效建仓区间/最终有效区间"，不要抓上游废弃区间。检查提取逻辑的优先级顺序。

## E-009 报告渲染层最终覆盖声明
**优先级：P2**
**问题：** 中间交易员计划里保留"最终交易建议:买入"，但系统最终动作已被 Strong Action Gate 降为 HOLD。读报告时容易混淆。
**修复：** 在最终报告输出中，对被最终门禁覆盖的中间层建议加声明，如：
> ⚠️ 上游买入建议已被 Strong Action Gate 降级，系统最终动作以 HOLD/等待触发为准。

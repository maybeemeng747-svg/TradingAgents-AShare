**Three-state contract** now enforced:
1. Analyst provides concrete value (e.g. `"gpt-4o-real"`) → preserved
2. Analyst writes `"unknown"` (no response metadata) → preserved
3. Analyst omits the field → fallback `"unknown"` (never fakes requested_model)

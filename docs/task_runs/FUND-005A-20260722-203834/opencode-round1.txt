+    """Extract the actual model name from the last LLM response chunk.

+    Returns the model name if available in response metadata, else None.

### 关键逻辑

1. **`_model_for_tier_with_fallback(config, tier)`** — 返回 `(resolved_model, fallback_from)`。当 tier 首选 key 为空而使用后续 candidate 时，`fallback_from` 记录被跳过的首选 key 名。
2. **`_extract_actual_model_from_response(chunk)`** — 从 LLM stream 最后一个 chunk 的 `response_metadata["model"]` 或 `["model_name"]` 提取实际模型名，不可用返回 `None`。
3. **`annotate_agent_traces()`** — 不再无条件覆写 `actual_model`；分析师运行时提供的值被保留，仅在缺失时回退到 config 派生值。
4. **7 个分析师** — 统一 pattern：`started_at = time.time()` 在流式调用前，`finished_at` 在调用后，`actual_model` 从最后一个 chunk 提取，写入 trace dict。
